# Alkamy Order Editor Pro walkthrough

Actual local demo using fictional Petal & Stem records. Synthetic English narration: ElevenLabs Adam, Eleven v4. Navigation waits are trimmed.

## 00:00:00 · Billing and shipping, inline

Pro adds an invoicing workspace to the WooCommerce order screen. Billing and shipping details are stacked, with lightly shaded fields for inline editing. Keep a separate delivery address, or use the same address as billing.

## 00:00:15 · Custom customer references

Add order references such as a purchase order or event date. Custom fields appear on your documents. Use Send to payment provider only for fields you want forwarded through a supported payment gateway.

## 00:00:29 · Order-specific document sections

Add headings and Markdown content to your document sections. Use the handles to change their order. The paper preview reflects section edits before you save the order, so you can check the wording and arrangement.

## 00:00:43 · Shared branding and document defaults

Set a shared logo and company details under Invoicing. Choose paper size, compact item spacing, and a footer style. Assign a different saved layout to each document type when you need different designs.

## 00:00:58 · Design PDF layouts with blocks

Use the WordPress block editor to design reusable PDF layouts. Arrange dynamic document areas with supported headings, paragraphs, images, and patterns. The item table has its own compact spacing control. Save the layout for future documents.

## 00:01:16 · Preview the right document

Preview invoices, quotations, packing slips, and delivery orders from the order screen. Packing slips and delivery orders keep quantities without monetary values. Your assigned document number is separate from the WooCommerce order reference.

## 00:01:33 · Preview and download PDFs

Use the paired Preview and Download controls for each document. Credit notes describe existing WooCommerce refunds; they do not create a refund. Payments continue through your installed WooCommerce gateway. Exporting a PDF does not charge the customer.
