The disposable installation used WordPress 7.1.3, WooCommerce 11.2.1 and SQLite. The shipped ZIPs were installed and their individual file hashes compared with the archives. Repositories retain unrelated work in progress.

## Fixes

Pro’s unpublished Free dependency is checked at runtime instead of being advertised as an available WordPress.org dependency. Without Free, no Pro document handlers load, and plugin administrators see installation/activation guidance. Guest users do not see the notice. Real WordPress deactivation/reactivation and all three loader-order cases passed. WooCommerce remains a standard header dependency.

The report gate no longer waives dependency warnings and rejects JSON objects masquerading as findings arrays. The test runner includes the installed ZIP’s source in coverage, uses a 512 MB test limit for Xdebug, and handles a missing environment correctly on macOS Bash 3.2. The missing-environment path intentionally refuses to run mutations.

## Remaining release gates

Managed QIT cannot run until the products are registered in the WooCommerce vendor account. Hosted MySQL CI, the declared PHP 7.4 minimum, the full supported version matrix, and multisite notice behavior were not executed in this pass. Marketplace pricing, support ownership and stable release versions remain submission decisions. No production installation, commit, push, public release or submission was performed.

The retained evidence is under the task workspace’s `work/quality-warning-fixes/`: exact PCP reports, JUnit and Clover reports, missing-dependency checks, gate regressions, build logs and package hashes. No warning filters or PCP suppressions were added.
